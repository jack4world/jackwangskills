# 新手最常撞的十种报错

每条的格式：报错长什么样 → 它在说什么 → 先去看哪里。

**先记住一条通用的**：报错栈那一长串，从上往下数，**第一行提到你自己写的文件的那一行**才是你要看的。上面全是库的内部代码。

---

## 1. `Cannot read properties of undefined (reading 'xxx')`

**在说**：代码想读某个东西的 `xxx` 属性，但那个东西根本不存在。

**先看**：不是出错的那一行本身，而是**那个东西是从哪来的**。打印它本身，看是不是 `undefined`。十次有九次是上一步没拿到数据。

## 2. `xxx is not a function`

**在说**：你把一个不是函数的东西当函数调用了。

**先看**：拼写（`toUpperCase` 写成了 `toUppercase`）、import 是不是漏了、或者你拿到的其实是个对象不是函数。

## 3. `Cannot find module 'xxx'` / `Failed to resolve import`

**在说**：找不到你 import 的那个东西。

**先看**：三种可能，按顺序排除：包没装（跑 `npm install`）、路径写错了（`./` 和 `../` 数错层）、文件名大小写不对（Mac 上不报错，部署到服务器就炸）。

## 4. `Unexpected token` / `SyntaxError`

**在说**：代码的语法不合法，解析器读到一半读不下去了。

**先看**：报错指的那一行**的上一行**。少个括号、少个逗号、引号没闭合，报错位置通常落在下一行。

## 5. `Port 4321 is already in use`

**在说**：这个端口已经被占了。

**先看**：多半是你之前起的服务没关。关掉那个终端窗口，或者换个端口。不是代码问题。

## 6. 页面白屏，控制台没报错

**在说**：代码跑完了但没渲染出东西。

**先看**：不是报错，是逻辑问题。打印你要渲染的数据，八成是空数组或空对象。空数组 `.map()` 出来就是什么都没有，不会报错。

## 7. `Hydration failed` / `Text content does not match`

**在说**：服务端生成的 HTML 和浏览器里跑出来的对不上。

**先看**：代码里有没有用到「每次都不一样」的东西：`Date.now()`、`Math.random()`、读浏览器本地存储。这些在服务端和浏览器算出来的结果不同。

## 8. `Type 'string' is not assignable to type 'number'`（TypeScript）

**在说**：你给一个只能装数字的地方塞了个文字。

**先看**：这不是运行时错误，是 TS 在你运行**之前**就拦住了你。常见来源：表单输入拿到的永远是字符串，要 `Number(x)` 转一下。

## 9. `EADDRNOTAVAIL` / `ECONNREFUSED`

**在说**：想连一个服务，但那边没人应答。

**先看**：那个服务起来了吗？地址和端口对吗？本地开发时最常见的原因是后端根本没启动。

## 10. `npm ERR!` 一大坨

**在说**：装包失败了。

**先看**：往上翻，找**第一个** `npm ERR!` 那行，后面的都是它的连锁反应。常见原因：网络、Node 版本不对（看 `package.json` 里的 `engines`）、`node_modules` 装坏了（删掉重装：`rm -rf node_modules package-lock.json && npm install`）。

---

## 表里没有的怎么办

按这个顺序做，不要跳：

1. **把报错原文完整复制下来**，不要只看最后一行
2. **找出错的是你的哪个文件哪一行**（栈里第一个你自己的文件）
3. **打印出错那一行用到的每个变量**，看谁不是你以为的样子
4. 还是不行，输入 `/learn-debug`，我陪你走一遍
