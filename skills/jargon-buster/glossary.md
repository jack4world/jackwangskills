# 常见术语白话表

按新手遇到的先后顺序排。表里没有的词，按 SKILL.md 的四段格式现场写。

## 最先撞上的

**API**：一个程序对外开的窗口。按规定格式递条子进去，按规定格式拿结果出来，不用管里面怎么干活。

**前端 / 后端**：前端是用户看得见、点得到的部分（页面、按钮）。后端是用户看不见的部分（算钱、存数据、验身份）。前端像餐厅的大堂，后端像后厨。

**框架 / 库**：库是你去调用它（你是主人，比如一个日期格式化工具）。框架是它来调用你（它是主人，你把代码填进它规定的位置，比如 Next.js）。

**依赖**：你的项目要用到的别人写好的代码包。`package.json` 就是这份清单。

**环境变量**：存在代码之外的配置值（密码、密钥、数据库地址）。放外面是因为它们不该被提交到代码仓库里让所有人看见。

## 数据相关

**数据库**：一个专门存数据、并且能快速查出来的地方。和存 Excel 的区别是：多人同时改不会乱，断电了数据还在，能按条件秒查几百万条。

**持久化**：「关掉程序数据还在」。存进数据库或文件就叫持久化；只存在内存里，一重启就没了。

**Schema（表结构）**：数据的表格长什么样：有哪几列、每列存什么类型。像 Excel 的表头，但强制执行。

**迁移（Migration）**：改数据库结构的操作记录。一条一条按顺序执行，这样每个人的数据库结构都能对上。

**缓存**：把算过一次的结果先存着，下次直接拿。像把常用的东西放在桌面上而不是每次去仓库找。代价是：仓库里的东西变了，桌上那份可能是旧的。

## 身份与安全

**Token**：登录之后网站发给你的一张临时通行证。之后每次请求你都带着它，网站就知道是你，不用重新输密码。会过期。

**认证 / 授权**：认证是「你是谁」（查身份证）。授权是「你能干什么」（这张卡能不能开这扇门）。先认证，再授权。

**Session**：服务器那边记着「这个人已经登录了」的一小段记忆。和 Token 的区别：Session 记在服务器，Token 记在你手上。

**HttpOnly Cookie**：一种浏览器里的存储方式，特点是网页上的 JavaScript 代码读不到它。这样就算页面被塞进了恶意脚本，也偷不走里面的登录凭证。

**哈希（Hash）**：把密码搅成一串没法还原的乱码再存起来。这样数据库被拖走了，别人也拿不到原始密码。存密码永远存哈希，不存原文。

## 写代码时

**函数 / 方法**：一段起了名字、可以反复调用的代码。给它输入，它给你输出。

**参数 / 返回值**：参数是你递进去的东西，返回值是它交出来的东西。

**异步 / await**：有些事要等（读文件、发网络请求）。异步就是「先去干别的，好了再回来处理」。`await` 是「这里我就等着，等好了再往下走」。

**Promise**：一张「以后会给你结果」的凭条。可能兑现（成功），也可能作废（出错）。

**类型（TypeScript）**：提前说清楚每个变量装的是什么（数字、文字、还是一个对象）。好处是写错了编辑器当场标红，不用等运行才发现。

**报错栈（Stack Trace）**：出错时打印的一长串。**从上往下第一行提到你自己写的文件的那一行，才是你要看的**，上面那些通常是库内部的。

## 工程习惯

**重构**：只改代码的结构，不改它的行为。改完功能和之前一模一样，只是更好读、更好改。判断标准：测试还是绿的。

**测试**：一段专门用来检查你的代码对不对的代码。你写一次，它每次都帮你检查。

**红 - 绿 - 重构**：先写一个会失败的测试（红），再写代码让它通过（绿），最后收拾一下结构（重构）。

**版本控制 / Git**：给代码存档，随时能回到任何一个历史版本，多人改同一份代码也不会覆盖彼此。

**分支（Branch）**：从主线上岔出一条，在上面随便改，改好了再合回去。改砸了直接扔掉，主线毫发无伤。

**CI（持续集成）**：你每次提交代码，服务器自动帮你跑一遍测试和构建。坏了立刻告诉你。

## 部署上线

**部署**：把代码放到一台一直开着的机器上，让别人能通过网址访问到。

**构建（Build）**：把你写的源代码打包成能在浏览器或服务器上真正跑的形式（压缩、转译、打包）。

**Serverless / 函数**：你只写一段处理请求的函数，不用管服务器怎么开、怎么扩容。没人访问的时候不花钱。

**域名 / DNS**：域名是网址（example.com），DNS 是把域名翻译成机器真实地址的电话簿。
